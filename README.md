# 抖音 AI 代理人（dybot）

一个跑在你本机上的「抖音 AI 代理人」：用它自己的抖音号刷推荐流、判断视频有没意思、转发给白名单里的朋友，并在私信里跟人聊天。

不是营销工具，不是爬虫，不是批量操作器。**它是给一个账号、几个熟人用的玩具。**

## 它做什么

| 能力 | 说明 |
|---|---|
| **自动回私信** | 每 8 秒轮询一次私信（只读 DOM，不发起请求），有新消息就生成回复、过安检、发送 |
| **看懂视频** | 你发来的视频卡片会被打开，读取标题、时长、平台给的「章节要点」、热评，然后针对内容回复 |
| **点赞（实验室）** | 看完视频后复用评分表再判一次，门槛更高；默认**关闭 + 预演**，每日上限可调（0~20） |
| **转发视频** | 扫推荐流 → 机械开关筛掉明显不合格的 → 模型判「有没意思」→ 发给白名单，卡片后面附一句现写的话 |
| **主动转发** | 两种触发：私信里说「给我发点视频」，或按概率定时自己挑一条 |
| **长期记忆** | 从聊天里抽取「一周后还用得上」的事实（严格筛选），也可手动增删改，每人上限 40 条 |
| **概率调度** | 转发和主动聊天各自有「检查间隔 / 命中概率 / 每日上限 / 安静时段」，不做准点定时 |

## 它明确不做

- ❌ 不关注陌生人、不刷评论、不点推荐流里的赞（只点**私信里发来的**视频，且默认关闭）
- ❌ 不做营销、不导流、不留联系方式
- ❌ 不使用你的主号（它需要自己的账号）
- ❌ 不替你承诺事情、不约时间、不谈钱、不传话
- ❌ 不上传任何数据到作者或第三方（除了调用你自己配置的 LLM API）

## 工作原理

```
你本机的 Edge（专用 profile + CDP 9222）
        ↑ 通过 Playwright 连上去
        │
  ┌─────┴──────────────────────────┐
  │ autoreply  轮询私信 → 生成 → 安检 → 发送      │
  │ digest     扫推荐流 → 筛 → 判 → 派 forward    │
  │ forward    定位好友 → 点分享 → toast 校验     │
  │ memory     抽取/注入长期记忆                  │
  │ schedule   概率触发 + 每日计数                │
  └────────────────────────────────┘
        │
  console（127.0.0.1:3200）← 你在这里改配置、看日志、跑一轮
```

**为什么必须用真实 Edge + 调试端口**：实测无头 Chromium 会在几秒内弹出滑块验证；用真实浏览器 + 独立 profile 才能稳定跑。

## 环境要求

- Windows（脚本是 `.bat`；核心逻辑跨平台，但没有非 Windows 的启动脚本）
- Node.js ≥ 18（不需要 `npm install`，全部用内置模块）
- Microsoft Edge
- 一个 **独立的抖音账号**（不要用你的主号），以及一个 DeepSeek API Key（或任何 OpenAI 兼容接口）

## 快速开始

### 1. 拿到代码，建立配置

```bash
git clone <仓库地址>
cd dybot
cp config.example.json config.json       # Windows: copy config.example.json config.json
```

`config.json` 不在仓库里（含你自己的白名单），必须自己复制一份。

### 2. 启动专用浏览器

双击 **`start-edge.bat`**。

它会用 `.edge-profile/`（独立 profile）+ 调试端口 9222 启动 Edge，并**自己检查端口是否就绪**。
在里面登录 **AI 那个账号**（只扫一次码，登录态留在 `.edge-profile/`）。

> 如果你之前用普通方式开过 Edge，新窗口可能被旧进程接管而拿不到调试端口 —— 脚本会检测并提示「关掉所有 Edge 窗口再试」。

### 3. 启动控制台

双击 **`start-console.bat`**，打开 http://127.0.0.1:3200 。

- 「白名单」页：填朋友昵称（**必须和抖音里完全一致**）和抖音号，勾选已验证
- 「人设」页：写角色卡（想验证效果用页内的**试一句**，只生成不发送）
- 「上限」页：每日转发/回复上限、轮询间隔
- 「自动」页：概率转发、主动聊天、记忆管理

### 4. 跑起来

「运行」页 → **「启动（只预演，不发）」** 先观察；确认没问题再点 **「启动（真发）」**。

想停下：点「停止」→ 关 Edge 窗口 → 关控制台窗口。

> 改动配置后**不必重启**：`autoreply` 每轮都重新读 `config.json`。但改了代码必须重启进程。

## 控制台一览

| 页签 | 内容 |
|---|---|
| 人设 | 角色卡（长文）、试一句（不发送）、它「知道你」什么、禁止话题 |
| 判据 | 评分表（27 加分 / 20 减分 + 门槛）、**初筛开关**（时长、关键词、短文案阈值、三个正则）、硬禁区锁死不可改 |
| 白名单 | ≤ 5 人，昵称 + 抖音号 + 已验证标记 |
| 上限 | 每日转发上限、每日回复上限、单视频收件人上限、同视频冷却、轮询间隔 |
| 运行 | 状态、额度、事件流、体检、日志导出 |
| 转发 | 手动扫一轮推荐流（预演 / 真发），可选只发给某人 |
| 自动 | 概率转发、主动聊天、记忆列表（增删改）、重置（调度 / 今日发送量 / 记忆 / 日志） |

控制台的「体检」会检查：配置文件、CDP 端口、标签页数、登录态、人机验证、白名单可达性、进程状态。

## 配置字段（`config.json`）

| 区块 | 关键字段 |
|---|---|
| `persona` | `character`（角色卡全文，优先使用）、`selfIntro`/`tone`/`systemNote`（角色卡为空时兜底）、`knowsAboutMe`、`forbiddenTopics` |
| `rules` | `blocked`（硬禁区，8 条，锁定）、`interesting`/`notInteresting`（判定判据）、`maxDurationSeconds`、`minConfidence`、`switches`（8 个机械开关） |
| `friends` | `{name, douyinId, verified}`，`verified=false` 的不会被发送 |
| `limits` | `dailyOutgoingCap`、`dailyReplyCap`、`maxRecipientsPerVideo`、`sameVideoCooldownHours`、`sessionMinutesMax`、`pollSeconds` |
| `digest` | `enabled`、`chance`、`everyMin`、`perDayMax`、`max`、`top` |
| `proactive` | `enabled`、`chance`、`everyMin`、`perDayMax`、`perConvPerDayMax`、`idleHours`、`quietHours`、`requireMemory` |

API Key 不放这里，放 `state/llm.json`（被 gitignore）。

## 安全与风控护栏

- **日限额**：转发、回复各自按自然日累计，跨重启不重置
- **去重**：同一视频 24 小时内不重复发给同一个人（按 `video_id`）
- **发送前二次校验**：点击会话后读「当前会话」标记，按 Enter 前再验一次；不匹配就取消并清空输入框
- **人机验证**：识别到滑块/拼图 → 自动停 30 分钟，期间不碰浏览器也不调模型
- **失败熔断**：连续 3 次发送失败 → 停 10 分钟
- **单实例锁**：原子锁 + 心跳，防止两个进程同时回复同一条消息
- **标签页隔离**：转发和读视频各用临时标签页，用完即关，启动时清理残留；永不关闭最后一个标签页
- **日志脱敏**：手机号、身份证、银行卡、邮箱、链接写入日志前打码
- **控制台鉴权**：所有写操作要 CSRF token；消息文本进 DOM 前转义

细节与威胁模型见 [SECURITY.md](SECURITY.md)。

## 实验室（不成熟功能）

「实验室」页签里放的是还没稳定到能进主流程的东西。目前有一项。

### AI 视频总结

抖音自带的 AI 会给视频生成整片摘要。这条链路能把它取出来，让机器人真正知道"这条视频讲了什么"，
而不是只看标题和评论。

**手动用**：输入视频 id → 点「取 AI 总结」→ 等 10~15 秒 → 面板里显示总结全文和逐步过程。
失败会留下截图（`state/lab/`）和原因，方便定位。

**接入用**：同一页有开关，控制 `config.lab.aiSummary`：

| 字段 | 默认 | 说明 |
|---|---|---|
| `enabled` | `false` | 关掉完全走原逻辑（只读标题/章节/评论），不多花时间 |
| `preLine` | `我看看` | 取总结前先回的那句；留空则不先回 |
| `maxWaitMs` | `40000` | 取总结超时，超时退回原逻辑 |

打开后：收到转发的视频 → 先回一句 → 取总结（约 10~15 秒）→ 带着总结生成回复。

**限制**：整条链路靠坐标点击，所以 **Edge 窗口必须在前台可见**；取总结期间该会话被占住。
失败不会影响回复，只会退回原逻辑。

**三道闸（都已实现）**：

| 闸 | 行为 |
|---|---|
| **缓存** | 同一条视频只取一次，存在 `state/summaries.json`（最多 300 条）。命中时 0 秒返回 |
| **不可见跳过** | 检测到 Edge 窗口最小化 → 直接跳过（不白等 40 秒） |
| **失败熔断** | 连续 3 次失败 → 暂停 30 分钟，期间全部走原逻辑 |

**转发前复核**（`digest.summaryRecheck`，默认 true）：评分过关、准备发送的那 1~2 条，
会再取一次总结并**重新判一遍**；判不过就不发。只在 `lab.aiSummary.enabled` 打开时生效。
实现见 `lib/videosummary.mjs`（五步：弹窗打开并校验 modal_id → 点 AI 入口 → 点 AI抖音 页签 →
在 iframe 里发「视频总结」→ 抓回复并裁剪）。

## 已知限制

| 限制 | 原因 |
|---|---|
| 看一条视频要 **18~25 秒** | 要开临时标签页 → 进推荐流 → 开浮窗 → 点会话 → 滚到底 → 点封面 → 读详情 → 关标签页 |
| 一次只能服务 **约 5 个人** | 每轮只点开一个非当前会话，人越多每人被检查的间隔越长；服务端硬限 5 人 |
| 对话上下文只有 **最近 6 条** | 每次从页面实时读，不落盘 |
| 长期记忆每人 **40 条** | 超出后挤掉最旧的 |
| 弹验证会中断服务 | 需人工过验证；过完点「停止」再「启动」 |
| 抖音改版会破坏选择器 | 卡片类名、章节要点入口、章节/编辑框结构都可能变 |
| 表情包只被识别为 `[表情包]` | 图片语义读不到 |

## 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 启动后立刻停，日志 `连不上浏览器的调试端口 9222` | Edge 是普通模式启动的 | 关掉所有 Edge 窗口，跑 `start-edge.bat` |
| `start-edge.bat` 一闪就关 | 文件被存成 LF 换行 | 用仓库里这份（CRLF），别用编辑器重存 |
| 白名单里的人收不到 | 昵称和抖音里不一致，或还没互关 | 用「运行」页的**体检**看「白名单可达」那一项 |
| 回复发错人 | 极少见：会话列表在点击瞬间重排 | 已有三道校验；若仍出现请提 issue 并附日志 |
| 控制台打不开 | 3200 被占 | 改 `CONSOLE_PORT` 环境变量，或关掉占用进程 |
| 视频读成空内容 | 页面还没渲染完就抓了 | 已改为"轮询等就绪 + 重试一次"，并在日志里记下 URL/原因 |
| 记忆写着「8 条」但只能看到 5 条、也没有「展开」 | 接口把 facts 截断了（`slice(-5)`），前端以为没有更多 | 已改成返回全量（上限 200）；写接口时注意 `count` 与 `facts.length` 要一致 |
| 页面某块空白、又不报错 | 渲染函数里抛错被 `catch{}` 吞了 | 已加顶部错误条：会显示「哪个函数 + 什么错」；看到就把它发我 |

## 自检命令

```bash
node lib/rules.selftest.mjs     # 判据机械层 9 个用例
node lib/llm.mjs --test         # 模型通道是否通（会打印打码后的 key）
node lib/check.mjs              # 浏览器/登录态检查
node lib/autoreply.mjs --once   # 单轮预演（不发送）
node lib/digest.mjs --max=3     # 扫 3 条只判不发
```

## 开发说明

- 零运行时依赖，只用 Node 内置模块 + DSH 环境里的 `playwright-core`（通过 CDP 连接，不下载浏览器）
- 所有路径从项目根算起（`lib/paths.mjs`），可用 `DYBOT_ROOT` 覆盖
- 配置是可编辑 JSON，控制台与程序共用同一份，不做两套
