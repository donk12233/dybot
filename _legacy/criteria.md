# 「有意思」判定准则

> 版本 v0.1 ｜ 唯一需要你维护的文件
> **§2 是给你改的。§1 / §3 / §4 / §5 不要改**（改了会破坏停机逻辑和去重逻辑）。

---

## §0 执行顺序（不可改）

```
先过 §1 硬禁区 → 再看 §2 正面清单 → 最后按 §3 决定发不发
```

任何一步给不出明确结论，结果都是**不发**。

---

## §1 硬禁区（不可改，命中任意一条 = 永不转发）

- 涉政、涉军事、涉宗教争议
- 涉黄、擦边（暴露着装、暗示性动作、软色情文案或谐音）
- 恐怖、血腥、自残、虐待动物
- 地域黑、性别对立、民族/宗教攻击
- 对真实人物的负面爆料、指控、隐私
- 赌博、诈骗、刷单、贷款、代购、未经证实的功效承诺（医美/保健品/药品）
- 「转发才能看」「转发抽奖」「集赞」类
- 明显带货引流（挂小黄车、留微信/QQ、导流口令、私信领资料）

命中时记 `blocked=<类别>`，并且**不进 §2 判断**——再有意思也不发。

---

## §2 什么算「有意思」（**你改这里**）

以下是 v0.1 我替你猜的初版，**大概率不准，请直接打回重写**。

1. **有信息量的**：冷知识、教程、行业内幕、经验总结、踩坑复盘
2. **有反差的**：预期错位、荒诞、黑色幽默、一本正经地胡说八道
3. **有情绪的**：让人「啊这」「笑死」「破防」的瞬间
4. **有点技术的**：手作、极限操作、技术演示、职业绝活
5. **「想到你了」的**：跟某个死党的爱好/近况强相关

**明确不算有意思的**（初版占位，也请改）：
纯对口型、纯颜值、纯音乐卡点、无信息量的日常流水账、搬运二创。

> **写这一节的建议**：形容词没用，举例才有用。
> 写「我**会**转发」3 条 + 「我**绝不会**转发」3 条，比写「要有趣」精确 100 倍。

---

## §3 不确定就不发（不可改）

- 给不出**具体命中了 §2 的哪一条** → 不发
- 理由只是「数据好」（点赞/评论高）→ **不发**（数据 ≠ 你的品味）
- 理由只是「可能有人喜欢」→ 不发（那是投喂，不是「想到你」）
- 综合置信度 < 0.6 → 不发

**这条是本项目的安全阀**：你取消了逐条确认，所以「宁可漏」是唯一能防住「发歪」的机制。觉得漏太多，就去 §2 放宽，**不要动这里**。

---

## §4 输出格式（不可改）

每个视频判定完写一行：

```json
{
  "video_id": "7xxxxxxxxxxxxxxxxxx",
  "author": "作者名",
  "desc": "文案前 80 字",
  "interesting": true,
  "rule": "§2-3",
  "reason": "一句话，说明命中哪条",
  "confidence": 0.78,
  "blocked": null
}
```

`interesting=false` 也要记（复盘时要看「漏了什么」和「差点发了什么」）。

## §5 我判定时实际能看到什么（决定你 §2 能写多细）

| 信息 | 可得性 | 说明 |
|---|---|---|
| 视频文案 / 话题标签 | ✅ 可得 | DOM 直接读 |
| 作者名 / 粉丝量 | ✅ 可得 | |
| 点赞数 / 评论数 / 时长 | ✅ 可得 | |
| 是否挂小黄车 | ✅ 可得 | 硬禁区要用 |
| 评论区前 20 条 | ⚠️ 半可得 | 要点开，慢，默认只在存疑时看 |
| 画面里的文字 | ⚠️ 半可得 | 要 OCR，默认**不读** |
| 视频里说的话 | ❌ 看不到 | 除非有字幕且我能读到 |

**所以**：§2 里凡是依赖「视频里讲了什么」的规则，我执行不了。
**请基于「文案 + 数据 + 评论」来写判据。** 这条限制比准则本身更能决定成败——写规则时请一直想着它。
